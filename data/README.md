# Данные кейса

Материалы, выданные организаторами. Это вход для агента, не его код.

| Файл | Что это |
|---|---|
| `acr/case-open-requests.docx` | открытые запросы кейса — формулировки заказчиков, на которых проверяем агента |
| `acr/example-dpp-pk-248h-business-analysis.docx` | образец ДПП повышения квалификации (248 ч) — эталон структуры |
| `acr/example-dop-obsh-24h-ai-intensive.docx` | образец общеразвивающей программы (24 ч) — эталон структуры |
| `acr/*.txt` | текстовые выжимки тех же docx, удобны для грепа и диффов |

Образцы разобраны вручную, их структура закодирована в `backend/app/render/docx_acr.py`
и в правилах автопроверки `backend/app/core/validate.py`. Код не читает эту папку
на старте: docx-шаблон собирается программно, чтобы его нельзя было сломать правкой файла.

Загрузить любой из этих docx в агента как референс можно через интерфейс
(«Прикрепить референс») или `POST /api/references/parse`.
