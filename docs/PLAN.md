## Найдено своими руками

- [x] **7. Мусор в названиях тем** — обрывок JSON `final_attestation': {`
      попал в заголовок модуля в готовом документе. Нормализатор отбрасывает
      обломки разметки и разворачивает объект, присланный строкой.
      `pipeline/skeleton.py`, `tests/test_model_output_variance.py`
- [x] **9. Точечная доработка темы** — пожелание методиста не доходило до

## Из требований кейса

- [x] **12. Только сервисы, доступные в России** — пункт чек-листа запроса 2.
      Правило в навыках плюс проверка кодом `SERVICE_UNAVAILABLE_RU`: промпт
      модель забывает, а замечание методист увидит в отчёте и в `.docx`.
      `skills/*.yaml`, `core/validate.py`, `tests/test_services_availability.py`
- [x] **13. Шрифты локально** — интерфейс грузил Inter и JetBrains Mono
      с `fonts.googleapis.com`. Теперь они в сборке (192 КБ, только нужные
      начертания и наборы символов), внешних запросов у страницы нет.
      `index.html`, `src/main.tsx`, `nginx.conf`

## Сверх плана

- [ ] **8. Свободный диалог с памятью контекста** — чтобы методист правил
      программу обычным текстом, а не только кнопками
- [x] **10. Адаптация программы** под другую аудиторию или объём часов.
      `POST /api/sessions/{id}/adapt` + форма в разделе «Выгрузки». Исходная
      программа не меняется, часы пересчитывает тот же солвер, методист видит

- [x] **11. Актуализация старой программы** с поиском устаревших тем.

      устаревшее с причиной и заменой, решает методист.
      `pipeline/refresh.py`, `skills/refresh.yaml`, `tests/test_refresh.py`

```bash
cd backend
python -m pytest tests -q                   # 199 тестов, без сети и без денег
python scripts/run_open_requests.py         # 5 запросов кейса с чек-листами
python scripts/check_topic_patch.py --url <адрес> --session <id>
```
